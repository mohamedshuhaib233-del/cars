# cars

Luxury 3D automotive scroll-driven sequence animation & interactive showroom featuring Ferrari SF90 Stradale, Ducati Panigale V4, BMW M 1000 RR, and Kawasaki Ninja H2.

## Features
- **3D Hero Section**: 60-120fps canvas scroll animation
- **Original Forged Alloy Wheels**: High-definition wheel studio
- **Active Aerodynamic Spoilers**: Carbon fiber wing systems
- **Authentic Superbike Racing Exhausts**: 4K on-track cinema & bike views
- **360° Studio Inspection**: Interactive turntable studio
- **Direct WhatsApp Concierge**: Instant booking & inquiry integration
